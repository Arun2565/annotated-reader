# annotated-reader

[![skills.sh](https://skills.sh/badge/arun2565/annotated-reader)](https://skills.sh/arun2565/annotated-reader)

Overlay MoonReader highlights on EPUB chapter text — like Apple Books.

## Install

```bash
npx skills add arun2565/annotated-reader
```

## Usage

```bash
python scripts/moonreader_reader.py file.mrexpt book.epub --output-dir out/
```

Reads your MoonReader annotations overlaid on the original EPUB chapter text. Includes floating TOC, syntax-highlighted code blocks, and progress tracking.
